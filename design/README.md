# Brand art

`scene-3d.html` is the Three.js scene used to render the logo (`public/logo-*.png`) and the home-page
banner (`src/assets/hero*.jpg`). To re-render: serve this folder next to `node_modules/three@0.170.0`
and open `scene-3d.html?w=1024&h=1024&mode=logo` or `?w=1600&h=640&mode=banner`. The live art uses the default sunset theme; `&theme=journey` gives the alternative "dark to light" look (night behind the
student, sunrise ahead); the banner is flipped horizontally before use.
